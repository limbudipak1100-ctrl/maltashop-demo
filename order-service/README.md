# MaltaShop Order Service

This service manages customer orders for the MaltaShop e-commerce platform.

## Responsibilities

- Create customer orders.
- Validate order information.
- Track order status.
- Communicate with the Payment Service.
- Publish order events for other services.

## Technology

- Python
- FastAPI
- Docker
- GitHub Actions

## Project

This service is part of the MaltaShop microservices prototype.
